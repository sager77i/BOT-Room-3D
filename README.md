# ☕ BOT Room 3D (Sujiraporn Cafe’)

ห้องสนทนา 3 มิติแบบ Interactive Multi-Agent Lounge (**Sujiraporn Cafe’**) จำลองบรรยากาศร้านกาแฟพร้อมเหล่าตัวละคร AI ประจำร้าน 5 คาแรคเตอร์ในร่างซูเปอร์ไซย่าและร่างสัญชาตญาณขั้นสุดยอด (Ultra Instinct) สนทนาแลกเปลี่ยนข่าวสารบ้านเมืองและกระแส **Talk of The Town** แบบเรียลไทม์ ขับเคลื่อนด้วย **p5.js WebGL**, ระบบสังเคราะห์เสียงพูดภาษาไทย **Edge-TTS Neural Voice + FFmpeg Pitch Shifting** และระบบเชื่อมต่อบทสนทนาอัจฉริยะ **Hermes Agent**.

## 🚀 ฟีเจอร์หลัก (Key Features)

1. **3D WebGL Virtual Cafe (p5.js):**
   - เคาน์เตอร์บาริสต้าพร้อมเครื่องชงกาแฟและควันไอน้ำพวยพุ่ง
   - โต๊ะกลางและโต๊ะข้างพร้อมเก้าอี้และของตกแต่ง
   - โมเดลตัวละคร 3 มิติ เคลื่อนไหว ขยับแขน ขยับขา เดินไปมาตามจุด Waypoints
   - หมุนมุมกล้องรอบทิศทาง 360° ด้วยการลากเมาส์หรือการปัดหน้าจอบนมือถือ
   - ระบบคำนวณตำแหน่งพิกัด 3D สู่หน้าจอ 2D (Smooth Lerp Projection) เพื่อแสดงกล่องคำพูด (Speech Bubble) เหนือศีรษะของผู้พูดพร้อมเอฟเฟกต์พิมพ์ดีด (Typewriter)

2. **ระบบเสียงพูดพากย์ภาษาไทย Neural TTS + FFmpeg:**
   - ใช้ Microsoft Edge-TTS คุณภาพเสียงระดับสตูดิโอ
   - ปรับแต่ง Pitch Shifting แยกโทนเสียงเฉพาะตัวละครด้วย FFmpeg (`asetrate` + `atempo`) ป้องกันปัญหา `NoAudioReceived` ทำให้เสียงอาม้า (คนแก่) และพี่ตู่ (หญิงวัยกลางคน) มีน้ำเสียงต่างกันอย่างเป็นธรรมชาติ
   - รองรับ Web Audio Unlocking บนอุปกรณ์ iOS และมือถือ

3. **Autonomous Multi-Agent Dialogue Engine (`relay.py`):**
   - ดึงข่าวจริงประจำวันแบบสดๆ (Live RSS News จาก ThaiPBS, มติชน, ข่าวสด, ไทยรัฐ)
   - ระบบหมุนเวียนหัวข้อทุก 10 นาที (Talk of The Town Sliding Window Rotation) ป้องกันการวนลูปซ้ำ
   - ประมวลผลบทสนทนาแบบผลัดกันพูด (Round-Robin) ผ่าน Hermes CLI / OpenRouter LLM
   - ทำความสะอาดข้อความ ขัดเกลาคำลงท้าย (เช่น นะลูก, จ้ะ) และลบสัญลักษณ์ส่วนเกินโดยอัตโนมัติ

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

```text

├── index.html            # เว็บแอปพลิเคชัน 3D Sujiraporn Cafe' (p5.js WebGL + UI)

├── audio/                # โฟลเดอร์เก็บไฟล์เสียงสังเคราะห์ MP3 ของบทสนทนา
```

## 🛠 วิธีการเปิดใช้งาน (How to Run)

### 1. เปิดชมห้อง 3D (Web Server)
ดับเบิลคลิกไฟล์:
```text
run_room.bat
```
หรือรันคำสั่ง:
```bash
python server.py
```
เปิดบราวเซอร์ไปที่: **`http://localhost:8099/`**

### 2. เปิดระบบสร้างบทสนทนา AI อัตโนมัติ (Relay Engine)
ดับเบิลคลิกไฟล์:
```text
run_relay.bat
```
หรือรันคำสั่ง:
```bash
python relay.py
```
บอททั้ง 5 จะเริ่มผลัดกันดึงข่าวดัง Talk of the Town มาสนทนา แลกเปลี่ยนความคิดเห็น และสร้างเสียงสังเคราะห์ภาษาไทยลงในโฟลเดอร์ `audio/` โดยอัตโนมัติ
